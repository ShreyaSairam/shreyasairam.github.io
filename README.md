# Shreya Sairam: Project Portfolio

Live site: https://shreyasairam.github.io

AI, data analytics and energy projects, each with a demo.

| Project | What it is | Demo |
|---|---|---|
| Out of Phase | Do batteries paid by market price help or hurt the local grid? Real data from Sydney and Delhi. | [Live demo](out-of-phase/index.html) |
| Quiet Exits | Savings quietly draining out of bank accounts, followed through six bank teams from SQL to a governed model and a call list. 1.06M real transactions. | [Live demo](quiet-exits/index.html) |
| Lumen | Team project, FEIT Hackathon 2026 (SMEC Spot Prize, Top 5). Privacy safe pedestrian counting and shade aware routing for Cremorne. | [Live prototype](https://lumen.yuanhaofeng.com/) |
| Facial Recognition Attendance | Face recognition check-in with present, late and absent tracking. | [Live](https://shreyasairam-projects.streamlit.app/attendance) |
| SignSpeak | Real time ASL letter recognition from a webcam, 95.2% test accuracy. | [Live](https://shreyasairam-projects.streamlit.app/signspeak) |
| Football Analytics Dashboard | Shot maps, xG, heatmaps and a SQL explorer for France at the 2018 World Cup. | [Live](https://shreyasairam-projects.streamlit.app/football) |
| WanderWise | Hybrid travel recommender with live weather, location and a Gemini chat panel. | [Live](https://shreyasairam-projects.streamlit.app/wanderwise) |
| Genetic Testing Decision Support | Symptom to gene matching for GPs with one recommended test. | [Live](https://shreyasairam-projects.streamlit.app/genomics) |

The five demo projects are working rebuilds of earlier university and personal projects, made on open datasets. Code: https://github.com/ShreyaSairam/portfolio

## Adding a new project
1. Put its files in a new folder, for example `finance-risk/`.
2. Copy one of the project cards in `index.html` and change the text, video and link.
