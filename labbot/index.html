Robot log

    1. Language to tool calls

    A parser turns your sentence into structured calls like move(sample 4, Analyser A). It checks them against lab rules first, so a blood count sent to the chemistry analyser gets corrected. A cloud LLM (Gemini) can plug in through a small worker; if it is off or slow, the on-device parser takes over.

    2. Planning the route

    Each trip is planned with A* on a grid of the lab. Turn on “Show A* search” to see which cells it explored. A wet floor sign or a nurse in the way triggers a replan from wherever the robot is.

    3. Running the job

    Urgent samples go first. Chemistry tubes are spun in the centrifuge before testing. Before each trip LabBot checks it has enough battery to get there and back to the dock, and charges first if not.
