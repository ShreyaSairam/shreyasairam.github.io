      1. Language to tool calls

      A parser turns your sentence into structured calls like move(bed 4, Analyser A). It checks them against lab rules first, so a blood count sent to the chemistry analyser gets corrected. A cloud LLM (Gemini) can plug in through a small worker; if it is off or slow, the on-device parser takes over.

      2. Planning the route

      Each trip is planned with A* on a grid of the lab. Turn on “Show A* search” to see which cells it explored. A wet floor sign, a spill or a nurse in the way triggers a replan from wherever the robot is.

      3. Running a shift

      In the shift challenge, turnaround time is measured the way labs measure it: from arrival to loading on the analyser. Autopilot always takes the sample closest to missing its deadline. Turn it off and see if you can beat it.
